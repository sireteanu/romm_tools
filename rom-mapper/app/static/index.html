Download folders
Any folder in these download folders can be a platform, also nested ones (Nintendo/Super Famicom). When two folders get the same platform, the one named like it wins. Levels: how deep the list goes. 1 level suits a folder with one folder per system (everything inside a system goes with it and isn't read, which is much faster); more levels show the subfolders, e.g. to exclude some. Folders must be mounted into this container at the same path.
